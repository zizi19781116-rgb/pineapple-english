请帮我从零开发一个仅供我个人使用的 iOS / iPadOS 英语学习 App。

项目重点是 iPad，iPhone 只需要兼容，不考虑 Android、Windows、macOS、网页端。

App 暂定名称：

「菠萝单词」

目标不是简单做一个背单词工具，而是做一个长期使用的个人英语学习系统。

优先保证：

1. 学习逻辑完整
2. 数据不会丢失
3. 后续容易扩展
4. iPad 使用体验优秀
5. AI 功能稳定
6. 界面简洁，不堆砌信息

技术优先采用：

- Swift
- SwiftUI
- iOS / iPadOS 原生开发
- SwiftData 或 Core Data 作为本地数据库
- Keychain 保存 API Key
- AVFoundation / AVSpeechSynthesizer 负责英式发音
- DeepSeek API 负责 AI 功能

不要做服务器。

所有个人学习数据默认保存在本地。

# 十二、错题系统

建立三个不同概念：

易错词

---

## 错题

用户答错后自动加入。

用户可以：

移出错题本
重新练习
标记已掌握
加入收藏
加入易错词

答对后不要自动立即移除。

允许用户自行设置：

连续正确多少次后自动移除。

默认可以为：

连续正确 3 次。

同时用户可以手动移除。

---

## 易错词

用于：

经常答错的单词。

满足例如：

累计错误 ≥ 3 次

可以自动标记。

同时允许手动：

加入易错词
移出易错词

---

## 薄弱词

代表：

不是每次都错，但记忆长期不稳定。

根据：

正确率
复习间隔
长期表现
近期错误
连续正确情况

进行判断。

允许系统自动标记，也允许用户手动调整。
