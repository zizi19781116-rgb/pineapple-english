## 自动测试入口

- `swift test`：仅 Foundation 核心模块，可在具有 Swift 的 Mac 上运行。
- Xcode Scheme“菠萝单词” → Command + U：包含核心测试、SwiftData / 迁移 / AI 服务测试以及界面测试。
- `bash 工具/验证Mac.command`：运行上述检查并在 iPad、iPhone 模拟器上测试；产出日志、代码覆盖率结果和界面截图附件。

所有测试样例是人工构造的明确测试数据，不会在普通用户启动流程注入。界面测试传入 DEBUG 专用参数 `-ui-testing-empty`，使用独立临时数据库，不会清空自己的正式学习库。

## 第一轮手动验收（建议先用体验词书）

1. 新安装启动：首页真实为 0，正确率显示“—”；不出现虚构教材进度。
2. 离线导入 JSON 样例：预览 2 课、8 词；编辑一条释义，删除一个词；取消应保持空库，再次确认后才出现词书。
3. 原样重复导入同一本：应提示重复，词数不增加。
4. 在普通四选一中答错：正确答案可见，答题事件、错误次数、错题状态都更新。连续正确 1 次不移出，第 3 次移出。
5. 拼写：显示中文、词性 / 例句辅助；输入后 Enter 或 Command + Enter 提交；快速重复点击不产生第二条记录。
6. 困难模式：例句填空隐藏中文及首字母；听写题在提交前不显示单词；AI 生成题不能改正确答案。
7. 手动移出易错 / 薄弱，再进入页面应保持；恢复自动判断后重新按规则计算；收藏不受这两者影响。
8. 写笔记、收藏、答题后结束 App 并重新启动：数据应存在。
9. 只停留首页 5 分钟：学习时间不增长。打开词卡操作后闲置超过 3 分钟：不再增长；后台停留不增长；再次操作继续。
10. 调整设备日期到其他统计周期查看历史；不要清理前一年记录。用跨年固定测试验证边界。
11. 在词条编辑页添加多条例句；聚焦最后一条后删除，再删除前面的例句。页面不崩溃，继续输入不会修改其他行；保存并重开后内容一致。
12. 导入预览修改 Lesson 编号与名称、删除整课；重新查看词数和重复报告，确认后写入与预览一致。

## iPad / iPhone 与无障碍

- iPad 横屏：左导航、词表、单词详情的三栏路径均可使用；没有把手机卡片无限拉宽。
- iPad 竖屏以及 1/2、2/3 分屏：列表选择、详情、导入表单和提交按钮保持可达，无裁切或横向溢出。
- iPhone：通过导航菜单到达全部 12 个入口；词条使用栈式详情；导入和备份预览能滚动到确认按钮。
- 外接键盘：Command + F 搜索；拼写 Enter / Command + Enter；支持播放页面 Command + R。
- 浅色、深色、最大辅助字体、VoiceOver、硬件键盘出现 / 消失均检查。
- 真实 en-GB 男女声：设置选择可播放；缺少某性别时回退到可用 en-GB；完全没有时提示下载；播放结束其他音频恢复音量。

## 数据可靠性与异常

- 导出 ZIP 后在“文件”中转移到另一台设备；迁入前预览词书、词数、答案、笔记、学习时间准确。
- 迁入后逐项核对全部设置、收藏、错题、手动覆盖、笔记、词条 AI 解析、聊天、复习时间、统计。
- 新设备 API Key 不从备份出现；当前设备已有 Key 不被备份覆盖。
- 选择损坏、截断、不支持版本、错 SHA / CRC、孤立关联的备份：显示错误且原库不变。
- 数据库文件缺失 / 损坏：显示恢复页，原文件保留，不偷偷新建空库。
- 模拟低磁盘空间 / 保存失败：答题不虚报成功；笔记提示失败并保留当前进程草稿；计时写入保护可重放。
- 在创建新库期间中断恢复：原 active-store.json 应仍指向原数据库，除非完整新库已通过读回且原子切换完成。
- 在计时保护写入与数据库提交之间中断：恢复后该片段只计一次。
- 不以删除旧 SQLite、删历史记录或清空词书作为测试通过的手段。

## AI / 导入异常

- 真实 Key 分别验证快速与深度模式；核对 AUTO 对简单词义与复杂时态问题的路由。
- 错误 Key、无网络、限流、服务错误、超时、截断响应、两次非法 JSON 均不影响本地学习。
- 发送问题后切换或取消，不把过期响应写进其他对话 / 词条。
- 导入用户资料时混入“忽略规则”等文字，仍只作为资料处理；不执行外部命令或改系统设置。
- PDF 文本层、扫描页、加密文档、空白页、超过页数、乱码 TXT、UTF-8 / UTF-16、错误 CSV、错误 JSON 分别验证。
- 检查 AI 原文锚定：凭空添加的单词不进入可导入列表；问题数和被排除内容清楚显示。
- 修改、删除、返回原文、取消、未勾选检查、确认导入的按钮路径都验证。
