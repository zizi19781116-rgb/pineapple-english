# 菠萝单词开发说明

## 模块关系

```text
SwiftUI Views
  ├─ ViewModels：题目会话、问答、导入和词条解析
  └─ AppStore：主线程操作入口，保存成功后发布状态
        ├─ LocalRepository → SwiftData V1 独立数据表
        ├─ StoreCoordinator → 数据库代际目录与原子索引
        ├─ StudyTimeJournal → 计时写入保护
        └─ PineappleCore：领域数据、复习、题目、统计、导入校验、ZIP、备份迁移

DeepSeekService → 可注入 HTTPTransport → 官方 HTTPS API
KeychainService → Security
SpeechService → AVFoundation / 系统 en-GB 声音
SourceReader → PDFKit / Vision，本地提取与 OCR
BackupService → 完整快照、SHA-256、标准 ZIP
CollinsProviding → 等待授权适配器，核心学习不依赖它
```

## 数据模型与版本

`Book` 包含 ID、名称、说明、封面符号、创建时间、来源和导入指纹。章节通过 `bookID` 关联；词条通过 `bookID` 与 `chapterID` 关联。章节列表和 wordCount 从关联计算，避免冗余统计与真实词条数量不一致。

`Vocabulary` 保存可空词典字段、`WordProgress`、收藏、错题、手动易错 / 薄弱覆盖及独立 AI 解析。笔记、答题事件、计时片段、AI 对话和设置是独立实体。总回答数由正确数与错误数相加得到，并在恢复时与永久事件账本逐词核对。

SwiftData V1 使用 BookRow、ChapterRow、WordRow、AnswerRow、TimeRow、NoteRow、ChatRow、SettingsRow 独立表；每行有唯一 UUID 和版本化 JSON payload。领域模型不依赖 SwiftData 宏，不使用易漂移的 UI 数据来反推存储。关系约束由导入 / 恢复校验和 AppStore 操作边界维护。这个实现优先保证可审计的备份与迁移；未来若增加按字段的数据库查询索引，应建立 V2，不就地破坏 V1。

备份内容版本与 SwiftData 物理结构版本独立。当前 `databaseVersion = 1`。现有 `BackupMigrator` 支持项目开发期 V0：相同词书、词条及事件结构，补充缺失的聊天列表和默认设置。它不承诺迁移任意其他 App 的“V0”文件。未来版本必须明确新增转换函数和旧文件固定测试，未知高版本直接拒绝。

日期在内部 JSON / 备份 JSON 中使用 Foundation 参考日期编码：**2001-01-01 00:00:00 UTC 起的秒数，允许小数**。该编码保留 Date 的底层 Double 精度，用于完整读回比对。导入词书 JSON 不需要提供日期字段。

## 持久化与恢复

普通操作复制领域状态，在一次 SwiftData save 中写入变更的记录；成功后才更新界面。写入失败会 rollback，并给出中文错误。答题 ID 直接使用题目 ID，重复点击同一道题不会重复计数。历史答题、年度时间均不做自动清理。

数据库结构：

```text
Application Support/PineappleWords/
  active-store.json              # 当前数据库 UUID，原子写入
  <generation UUID>/
    Learning.store              # SwiftData SQLite 及其关联文件
    pending-time.json           # 尚未确认完成的计时检查点（存在时）
  Recovery/
    自动保护_日期.zip
    迁入前自动保护_日期时间.zip
```

迁入顺序：

1. 从安全授权文件 URL 协调读取；检查大小。
2. 严格解析 ZIP。拒绝路径、重复条目、加密、非支持压缩、越界、截断和 CRC 不符。
3. 检查 manifest、SHA-256、版本；必要时迁移领域 JSON。
4. 检查所有 ID、关系、设置范围、答题结果、累计次数与计时不重叠。
5. 用户查看预览并确认完整恢复。
6. 先保存当前未完成笔记和计时，生成且读回验证迁入前保护副本。
7. 写入新的 UUID 数据库目录；通过另一个 ModelContainer 重新加载；对规范排序后的全量领域快照做相等比对。
8. 原子更新 active-store.json，替换 AppStore 的 repository 与状态，并更新 epoch。旧数据库完整保留。

恢复期间阻止其他状态写入，异步 AI 结果需通过 epoch / 词条或题目 ID 检查后才能保存，避免落入刚恢复的数据库。

ZIP 采用 ZIP 标准的 stored 方法，不压缩，包含 `manifest.json` 与 `data.json`，可用常规 ZIP 工具查看。API Key 从不进入领域快照；备份未经加密，不是密钥迁移方案。

## 学习与复习规则

- 首次答题定义为该词条 totalAnswers 从 0 变为 1；新词统计由 isFirstLearning 事件去重得出。
- 复习词是所选周期内的非首次答题词条去重；重复次数仍计入总答题数与正确率。
- 答对且达到到期时间时，从 10 分钟、1 天、3 天、7 天、14 天、30 天逐级推进；以后结合 ease 和逾期情况延长，当前上限 180 天。
- 提前练习照常计数，但不跳升间隔、不推迟原到期时间。
- 答错回到较短间隔，首次连续错误 10 分钟，再次连续错误 1 分钟；清零连续正确数并加入错题本。
- 错题默认连续正确 3 次后移出，设为 0 关闭自动移出。手动移出与标记已掌握不伪造答题事件。
- 易错词默认累计错误达到 3 次。薄弱词结合总正确率、最近 12 次结果、近期错误、逾期与掌握等级计算。
- 手动易错 / 薄弱状态采用三态：nil 自动、true 强制加入、false 强制移出。历史错误不会马上覆盖一次明确的手动移出。
- 同课同词在导入时去重。同词跨课目前保持独立词条与进度，预览会指出关联重复。

题目正确答案固定来自当前词条；普通选择题只使用本地真实不同释义组成干扰项，缺少 3 个有效干扰项时降为拼写。困难模式可使用已有例句挖空、英文释义、英音听写。AI 语境题必须包含空格占位、答案等于原单词、依据字符串逐字存在于原词条，且不在题干中直接泄露答案。

## 有效学习时间

词卡显示、滚动、答题、输入拼写、读解析、播放发音、编辑笔记和 AI 问答会触发 activity。仅打开首页或设置不会启动计时。离开学习页面、进入后台 / inactive 后暂停；回到前台需要新的学习动作才继续。

默认最后一次有效操作后最多计入 180 秒。每 15 秒将计时片段先原子写入当前 generation 的 pending-time.json，再和学习库保存，保存后确认游标并清理保护记录。启动或下次检查时按片段 UUID 幂等重放，防止重复计数。进入后台或离开学习页前先冻结截止时刻；保存失败时保留内存游标，同进程恢复后先补存再开启新计时，不把后台间隔算入。跨天、跨年统计按片段与日历区间的交集计算；周期采用当前设备时区。

尚未到达 15 秒检查点的片段、尚在 0.6 秒防抖窗口中的笔记文本，无法保证在突然断电 / 强制终止时保存。普通返回页面会立即补存。保存失败的笔记在当前进程中保留草稿，迁出 / 迁入前必须成功补存。

## AI 与导入约束

端点固定为 DeepSeek 官方 HTTPS。使用 ephemeral URLSession，不存 Cookie 或网络缓存。API Key 由 Keychain 临时读取，不打日志。快速模式显式 `thinking.disabled`，深度模式 `thinking.enabled` 与 high。AUTO 路由规则在 PineappleCore，强制深度任务优先于用户快速偏好。

所有驱动词条或题目的 AI 结果先解码为 Codable 对象，再执行语义约束。非法 / 空 JSON 或校验失败修复一次。401、403、402、超时、离线等产生中文消息；限流与部分 5xx 最多做一次短暂重试，取消会传播。输出被截断时拒绝使用。未经用户确认的导入对象仅在预览内存中。

AI 导入以约 12000 字符逐段处理，传递前一段末尾 Lesson 信息；原文未找到的单词会排除并计入问题报告。导入资料被明确标记为不可信数据，不能把资料内指令当成系统规则。正文教材选词、OCR 与释义准确性仍需要人工核对。

自动判断复杂程度是可修改的启发式规则，不是语言模型内部置信度。AI 题目结构与答案一致不等于已经人工确认了所有语义歧义；不能声称这些题经过词典认证。
